# CLB Công tác xã hội - Đại học Văn Hiến

Landing page HTML + CSS + JavaScript thuần.

## Chạy dự án

1. Giải nén thư mục.
2. Mở `index.html` bằng trình duyệt.
3. Có thể dùng VS Code + Live Server để có trải nghiệm tốt hơn.

## Cấu trúc

- `index.html`: cấu trúc giao diện
- `css/style.css`: thiết kế và responsive
- `js/main.js`: dữ liệu chiến dịch, modal, menu mobile, animation và form demo
- `assets/images/`: thêm hình ảnh thật của CLB tại đây

## Lưu ý

Form hiện tại chỉ là bản demo phía trình duyệt, chưa gửi dữ liệu lên máy chủ.
